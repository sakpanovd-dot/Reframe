## Задачи — по порядку приоритета

Каждую делай в своей ветке от `claude/dev` и оформляй PR в `claude/dev` (см. CLAUDE.md). В PR пиши по-русски: что сделано, какие проверки реально выполнены, что не проверено.

### 1. Простое обновление программы у брата (`update.ps1`)
**Статус:** скрипт `update.ps1` и раздел README сделаны в облаке (ветка `claude/temp-agent-next-tasks-wkeoja`). На Windows не запускался — проверить на ноутбуке: обычное обновление, «уже последняя версия», изменённый файл программы, запущенный Reframe, нет интернета.

Брат не программист. Сейчас для обновления нужны `git pull`, переустановка пакетов и — после последних изменений — обязательный повторный `download_model.py` (добавлена модель лиц; без неё 9:16 не запустится).
- Скрипт `update.ps1` в корне: проверка чистого рабочего дерева → `git pull --ff-only` → `pip install -r requirements-lock.txt` → `pip install --no-deps -e .` → `scripts/download_model.py` → понятное русское сообщение «Готово» или что делать при ошибке. Не делать `reset --hard`, ничего не удалять.
- Упомянуть в README в разделе установки.
- Проверить синтаксис PowerShell по возможности; честно написать, что на Windows скрипт не запускался.

### 2. Опция «выход 1080×1920» для исходников 1080p
Сейчас картинка не увеличивается: из 1080p получается 594×1056, монтажёр растягивает её сам. Нужна настройка в правой панели («Размер: как в исходнике / 1080×1920»), сохраняемая в `settings.json`, по умолчанию — как сейчас.
- Логика размера — в `planner.dimensions` или рядом (не в GUI); рендер уже умеет масштабировать кроп.
- Тесты: размеры плана для 1080p и 4K в обоих режимах; интеграционный экспорт маленького синтетического клипа с увеличением.
- QML smoke + просмотр снимка в обычном и минимальном окне (980×720): панель статуса должна оставаться видимой.

### 3. Уборка забытых временных папок
При аварийном завершении рядом с результатом остаётся `.reframe-<id>`. Запоминать в локальном состоянии (не в Git) папки, где создавались задания; при запуске приложения удалять в них только `.reframe-*` старше суток, если задание не выполняется. Ничего вне этих папок не трогать. Тесты на временных каталогах.

### 4. Оставшееся время (ETA) в строке прогресса
Сейчас видны этап и процент этапа. Добавить общую оценку оставшегося времени для текущего видео (этапы анализа и рендера — основное время; см. замеры в TESTING.md). Только когда оценка устойчива (не раньше ~10% пути), иначе ничего не показывать.

### 5. Тесты анализа лиц и губ на синтетике
`scenes.face_patches`, `scenes.lip_activity`, сопоставление лиц между образцами в `analysis.analyze`: движение головы без движения рта → ~0; изменение рта → > 0; склейка сбрасывает историю лиц. Без модели YuNet (подставные области).
